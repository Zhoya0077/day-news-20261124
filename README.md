# The World in One Day — Tuesday 24 November 2026

A single-page, newspaper-style image that summarises the world news of Tuesday
24 November 2026: six front-page story panels across tech, world court,
climate, the Middle East, war and health, plus a footer strip of shorter
reports. `draw_image.py` renders `entry.png` at 1024x1024 with Python 3 and
Pillow, and `main.ts` (Node 22, standard library only, no network) copies that
finished image into the output directory on every run, so repeated runs write
identical bytes.
